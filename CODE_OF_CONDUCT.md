# Code of conduct

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, and applies it in every project space: issues, pull
requests, discussions, and any other channel used for the project.

In short: be considerate, assume good faith, criticise work rather than people,
and do not harass anyone. A disagreement about a result is welcome; it is what
this project is for.

## Reporting

Report unacceptable behaviour to the maintainer,
[Samarth Hiremath](https://github.com/Samarth-Hiremath1), privately. Reports are
handled confidentially, and the enforcement guidelines are those of the
Contributor Covenant 2.1, linked above.
